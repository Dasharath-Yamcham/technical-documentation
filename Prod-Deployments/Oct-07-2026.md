# Mr. Yoda – Release Highlights

The major highlight of this release is the **new version of the Mr. Yoda website design**, along with several functional enhancements, improvements, and critical fixes across the platform.

## Key Release Highlights

### 1. Website & Admin Panel

- Launched the **new redesigned version of the Mr. Yoda website** with an updated UI/UX and improved user experience.
- Implemented **Multiple Membership** functionality.
- Introduced the **Premium Visit Booking** flow.
- Added **Outstation Save Address** functionality.
- Added **Collection Charges for Lab and Outstation**.
- Added **User Contact Us details in Admin with follow-up tracking**.
- Added **Customer Referral Doctor Onboarding notification** to the CD Team.

### 2. Live Tracking

- Added **Hub and Zone search and multi-select filters**.
- Live Tracking now displays **Phlebo locations instead of Riders**.
- Added Phlebo live tracking along with the order in **Order Tracking**.

### 3. Phlebo Dashboard & Attendance

- Fixed **Lab Delivery Count**.
- Added Hub search and multi-select filters.
- Added **City name beside Shift name**.
- Added **Clock-out image capture**.
- Fixed Latitude/Longitude navigation to Maps.
- Added Phlebo name and City details in Attendance.
- Added **daily completed order count** along with KM travelled.
- Added selected-row highlighting.
- Updated Attendance Excel export to include **Leaves and Week-offs**.

### 4. Phlebo Scheduler & Order Tracking

- Made Scheduler cards dynamic.
- Fixed Date Range functionality.
- Added search and multi-select functionality across filters.
- Added **Expired Slot count**.
- Fixed selected-date persistence and defaulted Order Tracking to **today**.
- Added **City, Hub and Report Status filters**.
- Added Hub/Lab drop times.
- Fixed assigned orders showing as **Unassigned**.
- Added direct **Assign** option for unassigned orders.
- Replaced ETA with **Collected Time**.

### 5. Phlebo Mobile App

- Added **Patient Age, Gender and Mobile Number**.
- Fixed Hub Order status/state handling.
- Fixed OTP/destination navigation flow.
- Fixed duplicate **Collection Charges** issue.

### 6. Client Orders

- Implemented separate **Client Order flow in Admin**.
- Added Yes/No option for **Home Collection Charges**.
- Added separate B2B and B2C invoices.

### 7. Doctor & Settlement

- Removed **Membership Discounts and Rewards** from Referral Doctor Orders.
- Enabled Doctor Discount for Customer Doctor Referral Orders.
- Added support for **Multiple Doctor Order Settlements** with settlement-status filters.
- Added **Doctor Order Settlement Invoice generation** with preview functionality.
- Added separate tracking for **Doctor Onboarding Bonus**.
- Added separate tracking for the onboarding bonus that is only used for order creation.

### 8. Leads

- Implemented **Lead Order Generation** with filters and export functionality.
- Disabled Payment Approval when **Visit ID is not available**.

### 9. Critical Fixes

- **Client Selection – Admin Discount Issue**
- **Settlement – LIS Showing Due**
- **Visit ID Not Created – 500 Error**
- **Sample Charges Calculation Issue**
- **Cancel Order – 500 Error**
- **Department Received – Edit Option**
- **Edit Order – Super Admin Restriction**
